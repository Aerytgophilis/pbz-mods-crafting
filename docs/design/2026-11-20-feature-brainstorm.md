# 红妆鬼斩增强：功能与可调数值头脑风暴（2026-11-20）

前提：规格 v3.1（mod README）已有的两个滑块档位是**花丛面积**（0 / +25% / +40% / +80% / +200%）和**花的存在时间**（15 / 25 / 60 s）。下面是可以继续加的东西，全部是**候选**，用户挑选后才进规格。

标注：**资产依据**＝第 0、1 步在资产里找到的现成东西，可以复用；**新机制**＝要自己写逻辑；**风险**＝滥强、性能或兼容性方面的担心。

## 1. 可调数值（滑块 / 档位）

| 候选 | 档位建议 | 依据 / 说明 | 风险 |
|---|---|---|---|
| 自动爆炸间隔 | 2 / 3 / **4** / 6 s | 已有参数 `tickInterval`，只是没做成档位。Boss 聚花是 2 s | 2 s 档配大面积会很强 |
| 花数量上限 | **25** / 35 / 50 | **资产依据**：Boss 被动把 `Max Flowers Default` 设为 50，同一个字段 | 上限越高，同屏花越多，性能和画面越杂 |
| 自动爆炸伤害倍率 | 0.2 / **0.4** / 0.6 / 1.0 | 已有参数 `tickDamageScale` | — |
| 自动爆炸杀气系数 | 0 / **0.5×** / 1× Boss 值 | 实测显示普通怪在花里 0.3 s 就破防，这一项主要影响 Boss | 要等 Boss 实测 |
| 对 Boss 单独倍率 | **1.0** / 0.7 / 0.5 | 新增一个 `bossScale`，只在 Boss 和精英身上额外乘。让“花海”对小怪爽、对 Boss 不碾压 | 需要可靠的 Boss 判定（标签） |
| E 引爆冷却 | 3 / **5** / 8 s | 已有参数 `manualCooldown` | — |
| 额外白花数 | 按等级（Lv25 +2 / Lv30 +4），可整体再 ×0 / ×0.5 / ×1 | 已有参数 | — |

## 2. 预设（一键档位）

把上面所有滑块打包成 3 个预设，玩家选一个就行，细调再改单项：

| 预设 | 思路 |
|---|---|
| **克制**（接近原版强度） | 面积 0、寿命 15 s、间隔 6 s、自动爆炸 0.2 倍、Boss 0.5 倍 |
| **均衡**（默认） | 面积 +25%、寿命 15 s、间隔 4 s、0.4 倍、Boss 0.7 倍 |
| **花海**（爽快） | 面积 +80%、寿命 25 s、间隔 3 s、0.6 倍、上限 35 |

Nexus 用户普遍喜欢“装上就能玩、想调再调”，预设比十几个裸参数友好。

## 3. 有“机制美”的新玩法（不是纯数值）

| 候选 | 描述 | 依据 | 评价 |
|---|---|---|---|
| **彼岸·极（Lv30 解锁）** | 资产里有 `GE_Hun_GuiTouBlade_Debuff_Effect_UltraFlower`（每 0.4 s 物理 0.3 + 杀气 0.3），第 0 步**没找到任何施加它的地方**，像是做了没用上的第三档花。可以让“同一朵花自动爆炸满 N 次”后升级为 UltraFlower 区域 | **资产依据**（未使用的 GE） | 很契合“满级才完整”的成长感，推荐 |
| **聚花（长按 E）** | 复用 Boss 的 `BD_AHua_GatheringFlower`：长按 E 把场上所有花收拢成一片聚花，每 2 s 判定一次，8 s 后一次大爆炸（半径 800），然后花全部消失。短按 E 仍是现在的“爆而不消” | **资产依据**（Boss 技能） | 玩家用 Boss 招式，很有记忆点；要验证 Boss 子弹在玩家阵营下是否正常判定 |
| **生生不息** | 敌人站在花里时，花的寿命暂停或缓慢回充；没人时正常流逝 | 新机制 | 奖励把敌人留在花里，符合武器“控场消耗”的身份；花会更持久，要配上限 |
| **连锁绽放** | 一朵花爆炸时，引燃一定半径内尚未爆炸的花（延迟 0.1 s 依次传播） | 新机制 | 视觉很好看；和合批逻辑冲突，要设计成“传播只触发一次合批” |
| **断情增幅** | Lv15 的“断情”期间，自动爆炸间隔缩短一半 | 资产有 `HasBuff_Ultimate` 标签 | 把 mod 和原版的爆发窗口连起来 |
| **花中吸血**（已是待定项） | 站在花里攻击会吸血，复用 Outlaw's Warblade 的吸血实现 | 待调查 | 加“每秒回复上限”和“只对活体”，防永动 |
| **白花轨迹样式** | 单目标时的轨迹：扇形 / 绕后 / 螺旋 | 新机制 | 纯观感，做成选项即可 |

## 4. 体验与兼容

| 候选 | 说明 |
|---|---|
| 自动爆炸特效强度 | 0 / 50% / 100%。花多的时候特效会糊屏，影响弹反判断（Neon 审计也提到） |
| 自动爆炸音量 | 同上，独立于原版爆炸 |
| 总开关热键 | 一键临时关闭本 mod 的全部改动（例如打某些 Boss 时想回原版） |
| 只对小怪 / 只对 Boss | 自动爆炸的作用对象开关 |
| Mods Menu 游戏内菜单 | 已在规格里：效果做完后接入。注意它占用 `hid.dll`，和我们现在的加载器入口冲突，接入时要换入口 |

## 5. 建议的取舍

- **v0.1（首发）**：只做规格 v3.1 已有的内容 + **3 个预设**。预设几乎没有额外开发量，对 Nexus 用户最友好。
- **v0.2**：彼岸·极、聚花，挑一个做（都有资产依据，最有“机制美”）；对 Boss 单独倍率；特效强度。
- **以后**：生生不息、连锁绽放、花中吸血、总开关热键、Mods Menu。
- **不建议**：把所有数值都做成滑块。参数越多，平衡越难保证，也越难写说明。保持“预设 + 少数关键滑块”。
