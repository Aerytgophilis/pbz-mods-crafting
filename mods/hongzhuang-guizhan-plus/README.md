# 红妆鬼斩增强（hongzhuang-guizhan-plus）

武器：红妆鬼斩（Scarlet Wraithblade）。技术路线见 `docs/decisions/0001-hongzhuang-route.md`。

## 原版行为（用户描述，第 0 步核实）

- 重击连段在地上铺彼岸花：范围内敌人减速、持续掉杀气。
- 花存在一段时间后自动爆炸并消失（Lv1 约 3 秒，Lv5 起约 15 秒）。
- 玩家按 **E** 可以主动引爆花，花爆炸后消失。
- 在已有的花上再铺花：旧花消失，新花覆盖这片区域，并且立即爆炸一次。
- F 蓄力（按住重击，Lv25 火照黄泉）：放出 1 朵白色彼岸花飞向敌人，接触后爆炸。

## 目标行为（设计规格 v1，2026-11-20）

### 效果 1：场地彼岸花

| 项 | 原版 | 本 mod |
|---|---|---|
| 存在时间 | 3 s / 15 s（Lv5+） | **不变** |
| 自动周期爆炸 | 无 | **每 `tickInterval` 秒爆炸一次，花不消失** |
| 存在时间结束 | 爆炸一次并消失 | **不变**：仍爆炸一次再消失 |
| 按 E 主动引爆 | 全部引爆，花消失 | 全部引爆，**花不消失**；E 引爆有 **5 s 冷却** |
| 在旧花上铺新花 | 旧花消失，新花覆盖并立即爆炸一次 | **不变** |
| 同时存在的花数量上限 | 原版上限 | **不变**（防止堆叠） |

### 效果 2：F 蓄力白色彼岸花

1 朵 → **5 朵**（分布方式：第 0 步看清原版生成方式后再定，默认扇形）。

## 平衡（防滥强）建议

以 Lv5+ 存在时间 15 s、tick 间隔 4 s 为例：一朵花在 4 / 8 / 12 秒各自动爆一次，15 秒消失时再爆一次，共 **4 次**；再加上每 5 秒一次的 E 引爆，最多约 **7 次**。原版一朵花只爆 **1 次**。不加限制，伤害和杀气削减会放大 4～7 倍。

建议默认值（全部做成可配置项）：

| 参数 | 建议默认 | 理由 |
|---|---|---|
| `tickInterval` | **取 Boss 阿花的花丛间隔，但不低于 4 s** | Boss 数值是为 AI 设计的；玩家输出手段更多，间隔不应更短 |
| `tickDamageScale` | **0.4**（自动爆炸的 HP 伤害为正常爆炸的 40%） | 让 15 秒内的总伤害约为原版的 2～2.5 倍，而不是 4～7 倍 |
| `tickAngerScale` | **1.0**（杀气削减不打折） | mod 的核心目标是持续削杀气，保留手感 |
| `manualCooldown` | **5 s** | 用户指定 |
| `manualKeepsFlower` | **true** | 用户指定；设为 false 即回到原版“引爆即消失” |

Boss 阿花的实际间隔要在第 0 步从资产（被动 GA 的 tick 计时器默认值、Boss 花的 `Get Lifetime`）和战斗录像里取得。拿到后再定 `tickInterval` 的最终值。

## 状态

第 0 步（只读解包）已完成，结论见 `docs/game-notes/scarlet-wraithblade-flowers-assets.md` 和 ADR-0001“第 0 步结论”。上面“原版行为”一节是用户描述，资产给出的修正：

- 每次铺花是一圈 6～14 朵；Lv5 前同时最多 6 朵，Lv5 起 25 朵。资产里没有“覆盖旧花”的逻辑，推断用户看到的是超上限时最旧的花立即爆炸并消失。
- 第 4 段轻攻击（`AAAA`）也铺一圈 6 朵花。
- E 引爆原版就有 0.4 s 冷却。
- 玩家花的爆炸本身不削杀气，杀气来自敌人站在花里时每 0.3 s 一次的 debuff。
- 白花需要“杀气强化”状态，每朵白花结束会留下一朵大花。

规格里“在旧花上铺新花”一行和 `tickAngerScale` 需要用户按上面的修正重新确认；`tickInterval` 暂定 4 s。
